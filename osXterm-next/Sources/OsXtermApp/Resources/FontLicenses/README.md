# Bundled terminal fonts

osXterm ships the following open-license monospaced fonts. They are copied
from the listed upstream release tags, and the matching license text is
included in this directory.

The default is D2 Coding because it includes Korean glyph coverage. These
files are application resources and are never copied from a user's macOS font
collection.
